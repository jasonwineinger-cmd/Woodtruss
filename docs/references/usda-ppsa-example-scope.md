**Historical program output; not a measured test, solver validation, or fabrication release.**

Values were checked in the rendered source, not just its searchable text.

- Tables II–IV (p. 13): the two loaded members are 2 (node 2 to 3) and 3 (node 3 to 4). Their horizontal intervals are 0–70.250 in and 70.250–140.500 in; their vertical drops are 23.410 and 23.420 in. Table V (p. 14) separately prints their analog lengths, 74.048 and 74.051 in. The 1.15 value is identified as a stress adjustment, not an added force.
- Table VII (p. 16): node 1 reaction is (+896.178, +1005.070) lb, node 2 (−833.472, 0) lb, node 5 (−62.705, +376.230) lb; all reaction moments are printed as zero. Summing the reaction forces and taking moments about the original Table II coordinate origin gives approximately (+0.001, +1381.300) lb and +94,542.250 lb-in. The report prints the vertical totals as ±1381.3 lb and the moment totals to two significant figures.

## Independent arithmetic and hold

Taking the tabulated intensity across the **horizontal intervals** gives −351.250 lb on each member, −1381.300 lb total vertical force after adding the point loads, and −94,542.225 lb-in about the origin when the two distributed resultants act at x = 35.125 and 105.375 in and the node couple is included. This agrees with the printed reaction totals within their rounding. Using the **sloped lengths** calculated from the printed node coordinates instead gives about −1419.295 lb and −97,211.912 lb-in, which does not agree.

As a separate local check, Figure 7 (p. 17) shows member 3 with vertical arrows and labels the intensity as 5 lb/in. Rotate each pair of Table VIII local axial and shear end-force sums into global coordinates using Table II: member 2 gives approximately (−0.0003, +351.2506) lb and member 3 (+0.0001, +351.2497) lb. These outputs independently balance the projected resultants, not the sloped-length resultants. Use the tabulated end actions rather than the rounded labels on the drawing for this calculation.

The manual describes load as applied continuously along a member (p. 4) and describes component input in pounds per unit length in the coordinate units (p. 11). That wording does not identify the denominator as actual length or projected length. A reading in which −5.000 is per inch of member length conflicts with both local and global output here. This supports **example-specific equivalence** to horizontal projection for the printed vertical components, not a universal input convention, a verified interpretation for oblique loading, or a silent conversion rule for another solver. No original executable or machine-readable input deck was independently replayed. Keep any future numerical comparison separate from modern code compliance, plate/saw data, shop release, and 50-ft capability.
