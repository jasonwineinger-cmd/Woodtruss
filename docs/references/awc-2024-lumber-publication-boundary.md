# AWC 2024 lumber publications: controlled input boundary

Checked November 22, 2026. This note identifies publications and updates. It supplies no design values, copied tables, or design decision.

| Publication | Official source and version boundary |
|---|---|
| ANSI/AWC NDS-2024, *National Design Specification for Wood Construction* | [AWC edition page](https://awc.org/resources/2024-nds/); [AWC cumulative errata and addenda, file updated September 22, 2026](https://awc.org/wp-content/uploads/2026/09/2024-NDS-Errata-and-Addenda-UPDATED-09.22.26.pdf). The cumulative file contains item-specific dates and applicability, including an addendum labeled March 2025 and updated in September 2026. The PDF title alone is not a reliable version identifier. Treat AWC's [March 2026 bundle](https://awc.org/wp-content/uploads/2026/03/2024-NDS-Errata-and-Addenda-03.23.26.pdf) as an earlier snapshot, not a substitute for the September file. |
| *2024 NDS Supplement: Design Values for Wood Construction* | [AWC Supplement edition page](https://awc.org/resources/2024-nds-supplement/); [official February 2024 Supplement update PDF](https://awc.org/wp-content/uploads/2024/02/2024NDS-Supplement-Updates-Errata_20240212.pdf) (electronic-version applicability); [official March 2025 Supplement bundle](https://web-media.awc.org/wp-content/uploads/2025/03/27192445/2024-NDSSuppAddendum3.27.25.pdf) (pages 1–2 carry the March 2025 addendum; page 3 carries the February 2024 addendum. Each section states print-and-electronic applicability in this bundle). AWC separately lists the Supplement in its [Updates & Errata index](https://awc.org/collection/updates-errata/). Both files are verified official updates, not an assertion that the set is exhaustive or that one globally supersedes the other. Recheck AWC's dedicated Supplement listing at intake before locking a controlled version. |

AWC distinguishes read-only viewing from purchased copies on its resource pages and says the NDS provisions and Supplement values should not be mixed across editions. The NDS errata are not a replacement for the Supplement's separate update set. Likewise, an original PDF or print copy does not prove which corrections it contains. Record the exact base copy and the updates that apply to it, including any corrections already incorporated; do not double-apply them.

### Supplement correction topics

- **March 2025, bundle pp. 1–2:** updates Hem-Fir (North) visually graded dimension-lumber reference values in Table 4A, its specific-gravity entry in Table 4C footnote 2 for machine-graded lumber, and the related multi-species/country grademarked entries in Table 4G. These are distinct from the NDS connection-table corrections; record which publication and item the intake uses.
- **February 2024, bundle p. 3:** adds Red Alder to the Section 2.1 species list and Table 4A grades. The standalone February PDF has electronic-only applicability wording; the February section included in the March bundle uses print-and-electronic wording. Treat these as corresponding witnesses of the same February correction, not two separate adjustments. Record which copy applies and whether the base edition already incorporates it.

## Controlled private use only

1. A responsible reviewer obtains lawful private access to the exact paired edition and checks applicable updates against the acquired copies and current official listings. Record document identities, edition/printing or file revision, official URLs, retrieval date, hashes of locally acquired files where allowed, the applicable correction set, and independent reviewer sign-off. Do not redistribute PDF bytes, screenshots, tables, extracted values, or embedded databases in this repository or public artifacts. Public availability, an errata link, and a view-only option are not permission to extract or redistribute content.
2. Bind any future authorized private material record to its exact published location and applicable corrections, with explicit species or species combination, grading basis, grade, product, size range and units. Match it independently to the actual specified material and identify the use and adjustment assumptions. Missing, ambiguous, mixed-edition, or superseded identities stop the lookup. Keep private source evidence and release authorization separate.
3. No jurisdiction, adopted code edition, amendments, design method, or project loading has been selected here. AWC's identification of the 2024 IBC reference does not establish local adoption or applicability. The current solver checks are preliminary: these links do not verify material properties, members, stability, connections, plates, inspection, or fabrication readiness. Any such determination needs project-specific engineering and an independently reviewed scope.

## Documentation checker

`assessLumberDesignInputEvidence(catalog, referenceValueId, evidence, expectedPublicationPair)` accepts a separately supplied `expectedPublicationPair` and compares it with `evidence.publicationPair`. The arguments remain optional for older callers; missing or mismatched pair evidence keeps the assessment on hold. The selected stock reference digest must identify the paired **Supplement** or one of its updates. The factor-scope rule digest must identify the paired **NDS** or one of its updates. A legacy same-digest reference used for both roles is not a substitute for those independently bound artifacts. Even an exact match yields documentation only, not verified sources, NDS readiness, or approval for structural use.


The separate `reviewLumberIntakeWithEditionEvidence` companion is for local documentation comparison. It hashes only the exact, complete artifact bytes supplied by the caller; a URL, excerpt, screenshot, file name, or self-declared digest is not a substitute for those bytes. Compare against independently declared expected artifact identities, and keep the reference-value and adjustment-rule roles and the intake quantity checks attached to the review. A matching fingerprint identifies the supplied bytes, not their completeness as an official edition, current status, official origin, or permission to access or redistribute them. The companion does not fetch publications, verify them live, grant a license, or establish a design value, member capacity, fabrication readiness, or release.
