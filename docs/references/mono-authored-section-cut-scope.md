# Authored mono-pitch elastic-frame section cut review

`studyAuthoredMonoElasticFrameSectionCuts` is a library-only readout for the [bounded synthetic mono frame](mono-authored-elastic-frame-scope.md). Each request selects an exact authored load state, directed member ID and its ordered endpoints, and a station in inches from that member's start. Retain the signed load basis and factors when a state comes from an explicit weighted case: the section actions come from that newly solved combined state, not from weighted reported peaks.

The readout reports signed local axial force, shear and bending moment (`N`, `V`, `M`) together at the same section and on the same side. It is not a combination of independently selected extrema. For an active concentrated action at an interior station, identify the left or right limit along that directed member. Do not use a single continuous value across a true jump or average the two sides. If coincident point actions cancel exactly while other loading remains, the solver retains the authored point station. Request left or right there; both recover equal force and moment, with no physical jump. A station with no point declaration takes continuous. At either member end, use the limit approached from inside the member.

A synthetic upper-web case isolates the section behavior in a controlled fixture. It is not validation of field loads, connections, manufactured stock, or the response of a physical mono truss. A mathematical section cut is not a shop cut. No strength check, site load, default code combination, allowable limit, connector or fabrication decision is implied.
